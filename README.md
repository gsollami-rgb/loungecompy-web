# LoungeCompy — web app (prototipo pubblico)

Questo ramo contiene solo il sito statico pubblicato con GitHub Pages.
Il codice dell'app (Expo + Supabase) resta sul ramo `main`.

- `index.html` — l'app, autonoma (HTML/JS, dati di riserva incorporati)
- `data/lounges.json`, `data/airports.json`, `data/meta.json` — i dati, aggiornati dal controllo settimanale
